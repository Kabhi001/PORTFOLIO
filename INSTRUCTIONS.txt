================================================================================
                          QUICK START (3 STEPS)
================================================================================

STEP 1: Open Terminal/Command Prompt
   - Windows: Press Win + R, type "cmd", press Enter
   - Mac/Linux: Open Terminal application

STEP 2: Navigate to Project Folder
   cd abhishek-portfolio

STEP 3: Install and Run
   npm install
   npm run dev

STEP 4: Open Browser
   Go to: http://localhost:3000

That's it! Your portfolio is now running! 🚀

================================================================================

1. VIEW YOUR PORTFOLIO
   - Open http://localhost:3000 in your browser

3. DEPLOY TO INTERNET
   Option A - Vercel (Recommended, Free):
      - Go to https://vercel.com
      - Sign up with GitHub
      - Click "Import Project"
      - Select your repository
      - Click "Deploy"
      - Your site will be live in 2 minutes!

   Option B - Netlify (Also Free):
      - Run: npm run build
      - Go to https://netlify.com
      - Drag and drop the "out" folder
      - Your site is live!

================================================================================
                          TROUBLESHOOTING
================================================================================

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "Port 3000 is already in use"
Solution: Run: npm run dev -- -p 3001

Problem: Build errors
Solution: Delete node_modules and .next folders, then run:
   npm install
   npm run dev

Problem: Can't see changes
Solution: Stop the server (Ctrl+C) and restart: npm run dev
